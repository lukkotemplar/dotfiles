# TIMETABLE

## PLAN A
Only RC, SO and CS. Ideally in the morning.

CONDITIONS:
- RC and SO must be in the 2MG
- If SO is in the 1MG, CS must be in the 2MG, and viceversa. By extension, this applies also to RC

POSSIBLE COMBINATIONS:
- RC and SO 2MG, CS 1MG
	- Tuesday: SO 9-11, CS 11-13
	- Wednesday: RC 9-11
	- Thursday: CS 11-13
	- Friday: SO 9-11, RC 11-13
## PLAN B
RC, SO, CS and VV. Ideally also in the morning.

CONDITIONS:
- As with plan A and...
- There is a collusion between RC and VV in the morning. VV wins in this case and the workaround would be either going to another slot in RC, or ask about the day's contents.

POSSIBLE COMBINATIONS:
- RC and SO 2MG, CS 1MG, VV 2MG
	- Timetable same as PLAN A, but on Wednesdays and Fridays VV is from 11-13.
	- The possible workaround is to have RC on TIT31, Thursdays from 15-17

RC, SO, CS, VV and ASO. What a nightmare!
POSSIBLE COMBINATIONS:
- RC and SO 2MG, CS 1MG, VV 2MG and ASO 2AG
	- Timetable same as PLAN A, but on Mondays and Wednesdays ASO is from 15-17
