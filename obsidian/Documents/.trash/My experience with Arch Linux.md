# MY EXPERIENCE WITH ARCH LINUX
After using Arch Linux for some time as my main Linux distro, I want to reflect on how it's so different from using other ones, and why it's very different
## BEFORE USING ARCH
I have been using Linux since october 2023, although I have known it since long ago.
The initial reason why I started using it was mostly to "try something different to Windows", and not replace it as my main system.
I didn't know many distros at the time; only Ubuntu, in fact. But i knew there were many more and I searched for a good starting point, and many people recommended Debian. It was stable and usable out of the box.
I thought the change was easy, but I spent almost a year with Debian and there was no day in which I didn't encounter any error. It was mostly a beginner's experience, but the next summer I completely ditched Debian and used only Windows again.
Not very long after, however, I tried a different approach with Linux. I knew that there was a way to start using it properly, and I started searching.
I found more distros, specifically the ones meant for beginners, and Linux Mint appeared. It looked nice and as it said: "the easiest distro". I installed it and began using it. It worked way better than Debian, to the point of using it more than Windows. But that didn't end there.
I started searching more and more. Config files, desktop environments, distros... I felt like I was accessing forbidden literature, and I was enjoying it. Then I stumbled with Arch.
## IMPRESSIONS
The first thing I noticed about it was that it didn't have a live installer like most distros had. Although it had an automated installer, the main point of this Distro was that the user mostly configured everything: the disks, the initial programs, the language... All with terminal commands. 
Naturally, the user needed to have some knowledge of a Linux system, and also to mantain it. That's when I learned about terms like 'rolling-release' and 'stable', among others.
What I had been using were 'stable' distros, which meant that the programs in them were a little bit outdated, but more stable. In contrast, Arch Linux was 'rolling-release', and although that meant that the programs were very up to date, they were also more prone to break unexpectedly, hence the emphasis on the user to mantain that distro.
Another thing I learnt from Arch was that it features an extense Wiki, covering a guide for most programs available. It is very well documented and the user was expected to use it almost everytime.
Knowing all that, I still sticked with Mint a little bit, partly because of the University and a reluctance to use a distro that seemed so hard to at least install it.
## FIRST STEPS
After some time, I decided to give a try to Arch and try installing it, but in a virtual machine.
The first installation, naturally, went wrong. There were many wrong things. I knew that would happen, and I continued trying until at the 3rd installation everything went OK.
What I first noticed is that there wasn't a "nice GUI to log in". It was just a terminal, and me.
Naturally, I wanted to use it, but at the moment I didn't knew what a Desktop Environment was!!
I installed KDE Plasma, and I used it like it was other distro. It felt good.
