# CONTROL DE FLUJO
## IF
Evalúa una condición y si se cumple ejecuta el bloque
```java
if (esto) {
	hazesto; //Si se cumple esto se ejecuta hazesto
}

if (2 <= 3) {
	System.out.println("Dos menor o igual a 3");
}
```

## IF-ELSE
Sigue 2 o más caminos distintos dependiendo de la condición
```java
if (esto) {
	hazesto;
} else if (otro) {
	hazestootro;
...
} else {
	hazfinalmenteesto;
}

if (3 > 5) {
	System.out.println("Tres mayor a Cinco");
} else if (4 < 5) {
	System.out.println("Cuatro menor a Cinco");
}
```
