# CONCEPTOS BÁSICOS
## COMENTARIOS
Hacen el código más legible
```java
// Comentario de una linea
/*
Comentario
de varias
lineas
*/
```
## MÉTODO Y SENTENCIA
- Sentencia: Instrucción de código que se ejecuta.
- Método: Conjunto de sentencias
```java
public static void main(String[] args) { //Método
	int x = 5; //Sentencia
}
```
## CLASE
Conjunto de métodos
```java
class HolaMundo { //Clase
	public static void main(String[] args) {
		int x = 5;
	}
}
```
## IDENTIFICADORES
Referencia a métodos, clases y otros objetos.
- No pueden empezar por un número
- No pueden contener caracteres especiales

Buenas prácticas al usar identificadores:
- Evitar tildes y ñ
- Métodos: Empiezan por minúscula
- Clases: Empiezan por mayúscula
- Separación de palabras con mayúscula (holaMundo)
