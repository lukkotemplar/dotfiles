# OPERADORES
## LISTA
- Negación: ! (! esto, lo contrario  de esto...)
- Y lógico: && (Esto && Esto otro, esto Y esto otro)
- O lógico: || (Esto || Esto otro, esto O esto otro)
- +: Suma
- -: Resta
- /: División (X / Y, X dividido por Y)
- %: Resto (X % Y, el resto de la división de X por Y)
- \*: Multiplicación (X * Y, X por Y)
- == : Iguales (X == Y, Devuelve true si X es igual a Y o false si son distintos)
- !=: Distintos (X != Y, Devuelve true si X es distinto de Y o false si son iguales)
- >: Mayor que
- <: Menor que
- >=: Mayor o igual que
- <=: Menor o igual que
